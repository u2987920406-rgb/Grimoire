# ADR-0003 — Grimoire comme méta-interface

**Statut : Accepted**

## Contexte
Le projet n'a pas besoin d'un héros unique entre toutes les aventures, mais a besoin d'une identité persistante et d'une navigation cohérente.

## Décision
Le grimoire magique est la méta-interface narrative persistante : portail vers les aventures et mémoire visuelle des découvertes.

## Conséquences
- les protagonistes peuvent changer ;
- les univers peuvent être indépendants ;
- la progression globale peut être montrée par pages, cartes, croquis et souvenirs plutôt que par XP scolaire ;
- la transition livre -> monde 3D doit être prototypée avant d'être considérée techniquement acquise.
