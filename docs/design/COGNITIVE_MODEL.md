# Modèle cognitif

## Capacités recherchées

Grimoire cherche à exercer, sans scores scolaires visibles :
- observation ;
- questionnement ;
- analyse ;
- décomposition d'un problème ;
- imagination ;
- créativité ;
- inventivité ;
- débrouillardise ;
- stratégie ;
- jugement ;
- esprit critique ;
- apprentissage par l'échec ;
- transfert de connaissances et de stratégies.

## Boucle

Observer -> Questionner -> Analyser -> Imaginer -> Choisir -> Agir -> Constater -> Corriger -> Comprendre -> Réutiliser.

Le joueur n'a pas à verbaliser toutes ces étapes. Le design crée des situations où elles deviennent utiles.

## Modèle mental du monde

Les objets doivent être compris par leurs propriétés et comportements plutôt que par des recettes arbitraires lorsque cela est raisonnable : masse, dimension, rigidité, résistance, flottabilité, friction, température, inflammabilité, corrosion, etc.

Le joueur n'a pas nécessairement accès aux valeurs numériques.

## Transfert

Une découverte importante doit idéalement réapparaître sous une autre forme : équilibre d'un radeau -> stabilité d'une charrette -> base d'une antenne, par exemple.

Le changement d'univers est une opportunité de vérifier que le joueur transporte une manière de penser plutôt qu'une recette.
