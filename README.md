# Grimoire

**Grimoire** est une plateforme d'aventures interactives autonomes destinée initialement aux enfants d'environ 8 ans.

Chaque aventure dure environ 45 à 90 minutes et transporte le joueur, depuis un grimoire magique, vers un nouvel univers. Les décors, personnages et problèmes changent ; le langage d'interaction et les principes de conception restent cohérents.

## Mission

Créer de véritables aventures qui développent progressivement la débrouillardise, l'observation, le raisonnement, l'analyse, l'imagination, la créativité, le jugement et l'esprit critique.

Le jeu privilégie l'expérimentation, les conséquences compréhensibles, l'apprentissage par l'échec et le transfert des découvertes entre contextes.
